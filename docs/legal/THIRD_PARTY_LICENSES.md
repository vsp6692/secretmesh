## How this is kept correct

| Check | What it does | Where |
|-------|--------------|-------|
| Policy | Fails on any dependency licence outside [license-policy.json](license-policy.json) (denied: GPL, AGPL, LGPL, SSPL, BUSL, non-commercial, unlicensed, unknown), except documented exceptions | `make license-check`, CI job `licenses`, pre-push hook |
| Notice drift | Fails if the tables below no longer match the dependency tree | `make license-verify`, CI |
| New pull requests | GitHub dependency review blocks vulnerable or disallowed licences in changed dependencies | `.github/workflows/pr.yml` |
| SBOM | CycloneDX SBOMs for Go and npm are produced for every CI run | `make sbom`, CI artefact |
| Full licence texts | `make license-texts` collects the licence and copyright files of every dependency; container images include them under `/licenses` | `deployments/docker/*.Dockerfile` |

## Not covered by the tables

- Build-time and test-only dependencies are checked by the policy but are not shipped, so they are not listed above.
- **Assets.** The web console uses the [Lucide](https://lucide.dev) icon set through `lucide-react` (ISC, with Feather's MIT portions). There are no bundled fonts or third-party images.
- **Specifications and generated code.** The OpenAPI 3.1 contract and its generated Go code (`oapi-codegen`) are SecretMesh's own output; the generator itself is a build tool.
- **Cloud provider SDK and API terms.** Use of AWS, Azure and Google Cloud APIs is governed by those providers' terms, not by this file.

## Adding or changing a dependency

1. Check the licence against [license-policy.json](license-policy.json). Anything copyleft or with unusual terms needs the maintainer's written approval and a documented exception.
2. Run `make license-check license-report` and commit the updated table.
3. If the new component needs attribution beyond the generated list, add it to the obligations table above.
